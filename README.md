# GENERIC-PROGRAMMING-Smart-Warehouse-Inventory-System

This repository contains the practical implementation of Generic Programming in Python using the typing module (TypeVar and Generic) for the EL 162 / 234 Object Oriented Programming course.

## 📌 Project Overview
Logistics companies store various product categories (e.g., electronics, books, food products, and spare parts). Rather than writing separate storage mechanisms for each category, this project implements reusable, type-independent, and maintainable classes using Python Generics.
